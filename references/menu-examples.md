# 菜品数据参考（menu-examples）

以下为推荐的菜品数据格式示例，供模型在推荐时参考。

## 数据字段说明

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| name | string | 菜品名称 |
| type | string | 菜品类型：中餐/西餐/日料/小吃/饮品/甜品 |
| region | string | 地域归属：川渝/广东/江浙/东北/西北/湖南/通用/日料/西餐 |
| tags | string[] | 标签：快捷/清淡/重口/治愈/健康/精致/过瘾/轻食 |
| cook_time_min | number | 制作时间（分钟） |
| price_level | string | 价格档位：低/中/高 |
| avoid | string[] | 忌口标记：含花生/含海鲜/含乳糖/生食/含麸质 |
| emoji | string | 代表 emoji |
| scene | string[] | 适用场景：早餐/午餐/晚餐/夜宵 |
| comfort | boolean | 是否适合情绪慰藉场景 |

## JSON 格式示例

```json
{
  "mode": "recommend",
  "dish": "番茄鸡蛋面",
  "type": "中餐",
  "tags": ["快捷", "清淡", "治愈"],
  "price_level": "低",
  "cook_time_min": 15,
  "reason": "15分钟就能吃上，热乎的汤面暖胃又暖心，适合不想等太久的时候",
  "emoji": "🍜"
}
```

## 使用说明

- 本文件为菜品数据参考，模型推荐时应基于此数据，不自创菜品
- 过滤时检查 `avoid` 字段是否命中用户忌口
- 场景匹配时检查 `scene` 字段是否包含当前用餐时段
- 情绪慰藉时优先选 `comfort: true` 或含"治愈"标签的菜品
