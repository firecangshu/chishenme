# 吃什么（饭点决策助手）🍜

30 秒帮纠结吃什么的你做决定。不再把"你想吃什么"的选择焦虑丢回给你。

## 能做什么

- **委托模式**：说"吃啥"，直接推荐最合适的
- **盲盒模式**：说"摇一个"，随机出结果，带惊喜感
- **安全过滤**：支持忌口/过敏/时间/预算过滤
- **纯对话**：不需要任何外部工具，纯文本输出

## 怎么用

对助手说：`吃啥` / `今天吃啥` / `摇一个` / `盲盒`，即可获得推荐。
